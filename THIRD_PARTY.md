# CodeStrike dependency and donor audit

`Cargo.lock` pins the tested crate graph. The local source manifests identify `ropey 1.6.1` as MIT (https://github.com/cessen/ropey), `regex 1.13.1` as MIT OR Apache-2.0 (https://github.com/rust-lang/regex), `serde 1.0.228` and `serde_json 1.0.149` as MIT OR Apache-2.0 (https://github.com/serde-rs), and `sha2 0.10.9` as MIT OR Apache-2.0 (https://github.com/RustCrypto/hashes). The stable ropey 1.6.1 line was chosen over the 2.0 beta. The separate combined Windows normal/build-dependency notice audit is not included in this standalone source checkout. A binary distribution must include a verified notice bundle for its exact contents. This checkout contains no binaries.

The pinned VectorCraft UI source at https://github.com/storytold/vectorcraft/tree/231a97dd51a8dc39f62449ee81bc490f7ba9fe5c was inspected. Its `crates/ui-egui/src/palette.rs` depends directly on VectorCraft's engine commands, tools, menus, i18n, and theme; its `crates/ui-egui/Cargo.toml` pulls the illustration engine and rendering graph. Copying that crate into CodeStrike would import unrelated illustration behavior. No upstream CodeStrike UI source was copied in this increment; the written plan keeps a narrow future adapter and attribution gate. No brand, assets, hosted service, or upstream executable was imported.

The native Windows preview adds registry crates `eframe 0.30.0` (MIT OR Apache-2.0, https://github.com/emilk/egui), `rfd 0.15.4` (MIT, https://github.com/PolyMeilex/rfd), and `png 0.18.1` (MIT OR Apache-2.0, https://github.com/image-rs/image-png) for app-generated QA captures. The source editor UI is CodeStrike-owned Rust code; no VectorCraft UI file was copied or claimed.

The explicit Cargo runner adds target-specific `windows-sys 0.61.2` (MIT OR Apache-2.0, https://github.com/microsoft/windows-rs) for a Windows Job Object and suspended-process start. The non-Windows runner refuses process execution until an equivalent lifecycle is implemented and tested.

The draft analyzer CI fixture applies a CodeStrike-reviewed patch to `rust-lang/rust-analyzer` commit `a0b58c0fe3e924302c1155e88c4a9454f86280c2` (MIT OR Apache-2.0, https://github.com/rust-lang/rust-analyzer). Upstream license texts and the exact source, patch, and test-only hook hashes are retained in [`third_party/rust-analyzer`](third_party/rust-analyzer/README.md). This source is built in a disposable CI checkout; no analyzer binary is included in this repository or made the installed/default server by this draft.
